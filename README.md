# 🐱 Mochi Life

Mochi Life é um mini jogo estilo Tamagotchi feito com HTML, CSS e JavaScript.  
Você cuida do Mochi alimentando, brincando e mantendo seus status equilibrados.

---

## 🎮 Funcionalidades

- 🍔 Alimentar o Mochi (aumenta a fome)
- 🎾 Brincar com o Mochi (aumenta a felicidade e diminui energia)
- 😴 Dormir (recupera energia)
- 📊 Sistema de status: fome, felicidade e energia
- 🖼️ Interface estilo aplicativo de celular
- 🎨 Visual personalizado com imagens feitas no Canva

---

## 🧠 Tecnologias usadas

- HTML5
- CSS3
- JavaScript
